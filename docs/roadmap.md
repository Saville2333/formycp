## 已知边界

- 模组自动切分是启发式，复杂排版建议先整理 Markdown 标题。
- “严格遵循模组”依赖提示词与检索上下文；前端能限制注入内容和状态越权，但不能数学证明模型永不越界。
- 多 PL 是同一浏览器中的多角色桌面，不是联机同步。
- AI 车卡 / KP 需要可用的 OpenAI 兼容接口。
